# Study Flight

A study timer that turns your session into a flight.

**▶ [Try it here](https://mochiandmilk.github.io/flight-study-timer/)**

## What it is

Pick where you're flying from and where you're going. The distance sets the length of your study session — a short hop is a quick session, a long haul is a long one.

Then you board. The background moves through the stages of a real flight while you work: the lounge, boarding, the cabin at altitude, descending through cloud, and landing when your time is up.

- Real airports to pick from, with a searchable list
- A gate number and seat assigned for every flight
- Ambient cabin sound and quiet lo-fi, generated in code — no audio files
- Pause and resume, or end the flight early
- Works on phones, tablets and computers

## How to use it

1. Choose your departure and arrival airports
2. Check the flight time, adjust it if you want
3. Board, and start studying
4. The plane lands when your session ends

## Built with

Plain HTML, CSS and JavaScript in a single file. No frameworks, no build step, nothing to install. The sound is generated live with the Web Audio API rather than played from files.

To run it yourself, download `index.html` and open it in a browser.
